Interest Calculator
A simple command-line tool to calculate simple interest based on user input.

Project Details
Project Name: Interest Calculator
Description: This project provides a Bash script that calculates simple interest given the principal amount, annual rate of interest, and time period in years.
Formula Used: Simple Interest = (Principal × Rate × Time) / 100
Features
Accepts user input for principal, rate of interest, and time period
Computes simple interest using the standard formula
Lightweight and easy to use from any terminal
Usage
bash

chmod +x simple-interest.sh
./simple-interest.sh
You will be prompted to enter:

Principal (P) – The initial amount of money
Rate of Interest (R) – Annual interest rate (in %)
Time Period (T) – Duration in years
Example

Enter the principal amount: 1000
Enter the rate of interest: 5
Enter the time period in years: 3
The simple interest is: 150.00
